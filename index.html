Héberger l'application gratuitement, sans API

L'application est un site statique : trois fichiers (HTML, CSS, JS) sans serveur ni base de données. Tout le calcul se fait dans le navigateur du visiteur. Résultat : hébergement gratuit chez plusieurs hébergeurs, aucune clé API, aucun coût, même hors ligne.

Option A — GitHub Pages (recommandée, permanente)

  1. Créez un compte gratuit sur github.com, puis un nouveau dépôt public (par ex. humanizzer).
  2. Uploadez les 5 fichiers : index.html, engine.js, app.js, tests.html, tests.js (bouton « Add file » puis « Upload files »).
  3. Allez dans Settings → Pages. Sous « Source », choisissez « Deploy from a branch », branche main, dossier / (root), puis Save.
  4. Attendez 1 à 2 minutes : l'application est en ligne sur https://votre-nom.github.io/humanizzer/. Gratuit à vie, HTTPS inclus.

Option B — Netlify Drop (la plus rapide)

  1. Mettez les 5 fichiers dans un dossier, compressez-le en ZIP.
  2. Allez sur app.netlify.com/drop et glissez-déposez le ZIP.
  3. Le site est en ligne en 30 secondes sur une URL fournie. Créez un compte gratuit (pas de carte bancaire) pour garder le site de façon permanente.

Option C — Vercel

  1. Créez un compte gratuit sur vercel.com (connexion GitHub possible).
  2. « Add New → Project », importez le dépôt GitHub créé à l'option A, cliquez Deploy.
  3. Site en ligne sur https://humanizzer-….vercel.app.
Choisissez UNE option. GitHub Pages est la plus stable pour un usage long terme ; Netlify Drop est la plus rapide pour tester aujourd'hui.

Utilisation hors ligne

Ouvrez simplement index.html en double-cliquant dessus : l'application fonctionne sans internet, les textes ne quittent jamais votre ordinateur.

Limite assumée : cet outil applique des règles de style et aide à reformuler proprement une source. Il ne fait aucune promesse de résultat face à un détecteur d'IA (Compilatio, Turnitin ou autre), car aucun tel chiffre n'est vérifiable de façon indépendante. Pour un travail académique, la protection réelle est de réécrire vous-même, de citer vos sources et de pouvoir expliquer chaque phrase.
